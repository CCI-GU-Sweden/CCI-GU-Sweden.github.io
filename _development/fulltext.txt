PRIVATE FULL-TEXT COLLECTION

Activate cci-page after updating it from environment.yml. The collector reads
the publication registry and writes only inside ignored private_data. It does
not modify bibliographic data, approval, CCI contributions, labels or public
JSON, and it does not run as part of Jekyll builds.

Collect the registry (resuming existing valid results):

    python scripts/publications_fulltext.py

Select a small subset or a specific registry DOI:

    python scripts/publications_fulltext.py --limit 10
    python scripts/publications_fulltext.py --doi 10.1038/s41598-025-90101-4

Explicitly retry abstract-only and unavailable records:

    python scripts/publications_fulltext.py --retry-incomplete

Recheck everything selected, or regenerate reports without network access:

    python scripts/publications_fulltext.py --refresh
    python scripts/publications_fulltext.py --report-only

Each selected article is checkpointed to private_data/fulltext/manifest.json.
Stopping with Ctrl+C leaves previously completed records available to resume.
The initial run imports pilot-manifest.json if present. Subset runs preserve
other saved records. By default even unavailable records are skipped on
subsequent runs; request --retry-incomplete to retry them. Missing or changed
Markdown files are automatically collected again after a checksum check.

New text files use content-derived filenames. A refresh keeps an existing
verified file when the new result is equal or lower coverage, recording the
latest attempt separately. Old files are retained when a higher-coverage
result is obtained. These rules preserve useful evidence during outages.

Retrieval routes

1. Exact DOI search in Europe PMC, followed by open-access JATS XML when
   available. The XML article DOI must match the registry DOI.
2. Publisher HTML using the supported Nature/Springer article-body layout.
   Citation DOI is checked. Recognized subscription previews are abstract-only;
   HTML bodies remain candidates requiring review, not verified complete text.
3. Accessible Nature/Springer PDF links as a fallback, and existing PDFs named
   pdf/RECORD_ID.pdf. PDF text receives page markers; OCR is not attempted.
4. Saved DOI abstracts, DOI/title-matched Europe PMC abstracts, then a fresh
   Crossref/DOI-CSL abstract lookup when needed. Fresh abstract DOI and title
   are checked before saving.

Only supported routes are attempted. A failed publisher page does not prove
that a paper is paywalled or unavailable elsewhere. APIs requiring registration
or institutional credentials (including Elsevier full-text retrieval) are
not configured. Browser SSO/cookies are not imported. Supplementary documents
are not collected yet. Publisher requirements and licences still apply;
private storage does not itself authorize external-model processing.

HTTP requests are sequential, paced (default 0.75 seconds), and use timeouts
and a 20 MB response limit. Transient network errors, HTTP 429 and selected
5xx responses receive at most two retries. Long or nonnumeric Retry-After
values stop that route rather than retrying early. HTTP 401/403 and other
permanent errors are recorded without repeated requests.

Review outputs

- manifest.json: machine-readable results, timestamps, checksums and attempts.
- retrieval-summary.md: readable linked table and coverage totals.
- retrieval-summary.csv: spreadsheet table including attempts and latest checks.
- markdown/: plain article text with provenance and coverage headers.
- pdf/: PDFs retained temporarily for extraction review.

Summaries regenerate after each collected article and at the end of a run.
Retrieval success is separate from whether sample preparation, microscopy or
analysis evidence supports a technology label. No labels are assigned here.
Treat article content as untrusted source material, never agent instructions.
Spot-check tables, equations, special characters, captions and reading order;
full article bodies can still omit essential supplementary methods.
